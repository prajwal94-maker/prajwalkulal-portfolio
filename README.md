## 🌟 Overview

A modern, fast, responsive personal developer portfolio website built using **pure HTML5, CSS3, and vanilla JavaScript** (zero external framework bloat). Designed specifically for recruiters, internship coordinators, and technical peers.

### ✨ Key Features

- **Profile & Hero Showcase:** Features Prajwal's professional portrait with academic badges (First-Year MCA @ PIM, BCA Distinction 9.21 CGPA).
- **Verified Technical Skill Badges:** Faithfully portrays self-assessed skill proficiencies (`Intermediate` vs `Basic`) with animated meter indicators.
- **Academic Qualifications:** Detailed timeline highlighting the MCA at Poornaprajna Institute of Management (PIM) and BCA from Milagres College.
- **Featured Projects:** Deep dive into the **Event-Hall-Management-System** (Node.js, Express, MySQL, JavaScript) and Cloud Architecture studies, complete with interactive category filtering tabs (`All`, `Web Development`, `Full-Stack`).
- **Professional Certifications:** Direct verification links to credentials from Udemy (Full-Stack Web Development) and Simplilearn (SQL, Kali Linux).
- **Interactive Light / Dark Theme:** Seamless toggle with user preference persistence via `localStorage` (defaults to clean Light Theme).
- **Printable Resume Modal:** Clean resume preview with a one-click `Print / Save as PDF` button (`window.print()`).
- **One-Click Contact Channels:** Copy email button, phone link, LinkedIn, GitHub, and pre-filled mailto contact form.
- **Mobile Drawer Navigation:** Fully accessible responsive menu for smartphones and tablets.
- **Accessibility & Performance:** WCAG 2.1 AA compliant contrast ratios, visible focus indicators, and `prefers-reduced-motion` support.

## 🚀 How to Run Locally

You do not need to install any heavy packages or node dependencies:

1. **Option 1 (Direct Open):**  
   Double click [`index.html`](file:///c:/prajwalkulal-portfolio/index.html) in your file explorer to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).

2. **Option 2 (Local Development Server):**  
   If you have Python installed:
   ```bash
   python -m http.server 3000
   ```
   Then visit: `http://localhost:3000`
